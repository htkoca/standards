# Agent instructions for this repo

See [README.md](README.md) for what this repo is and how it's used from other repos.

- **Don't use agent's built-in memory system for this project.** Durable facts,
  preferences, and conventions belong in this file (or the owning skill file),
  not in memory files. This repo is independent and portable;
  its guidance must not depend on a memory store that lives outside it.
